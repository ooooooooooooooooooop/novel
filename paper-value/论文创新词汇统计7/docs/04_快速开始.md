# 快速开始

> 目标读者：首次接手该项目的开发者

## 1. 核心流程

1. 计算创新度：`scripts/pipeline/run_v2_full.py`
2. 计算影响力：`scripts/pipeline/calculate_impact_v2.py`
3. 合并结果：`scripts/pipeline/merge_signals.py`
4. 可视化分析：`scripts/analyze/analyze_distributions.py`、`scripts/analyze/analyze_trends.py`

## 2. 常用命令

```bash
powershell -ExecutionPolicy Bypass -File tools/health_check.ps1

python scripts/pipeline/run_v2_full.py --dry-run
python scripts/pipeline/run_v2_full.py --years 2020-2022 --resume

python scripts/pipeline/calculate_impact_v2.py --pass 0
python scripts/pipeline/calculate_impact_v2.py --pass 1 --years 2020-2022 --resume

python scripts/pipeline/merge_signals.py --years 2010-2025

python scripts/analyze/analyze_distributions.py
python scripts/analyze/analyze_trends.py

python scripts/query/query_paper.py --title "transformer" --year 2020 --top 20
```

可选：为以上命令增加 `--config configs/your_profile.json` 覆盖默认配置。

## 3. 最小验证

- 检查是否存在核心输入库：`paths.rpu_db_path`
- 检查目标输出目录是否可写：`paths.innovation_output_dir/`、`paths.impact_output_dir/`、`paths.paper_signals_output_dir/`

## 4. 常见问题

- 路径问题：部分脚本使用绝对路径，迁移机器前需先统一配置。
- 内存问题：优先使用分年份运行与 `--resume`。
- 结果比对：先用单年运行验证，再做全量。
