# 影响力算法（V5 / V6）

> V5 设计来源：`IMPACT_V2_DESIGN.md`  
> V6 设计来源：`docs/reference/IMPACT_V6_DESIGN.md`

## 核心定义

`Impact = 论文引入的概念在后续学术系统中被采纳的广度 × 持续性`。

> V6.1 语义说明：当前主分字段语义为 `diffusion_impact`；`impact_score` 仅作为兼容别名保留。

## V6 核心升级

- 度量从“跨论文字符串匹配”升级为“同一概念的频率时间差分”
- 主信号改为 `Novelty Drop = max(0, log2(freq_current / freq_pub))`
- 贡献改为**概念级计算后聚合**：`concept_contribution = growth × concept_consistency_gate`
- 引入**概念密度惩罚**：高概念密度论文按对数惩罚稀释总分
- 引入**严格动词策略**：创造/定义类动词高权重，使用/分析类动词强上限（默认 ≤0.18）
- 默认四档动词权重：创造=1.0，改进=0.6，使用=0.2，分析=0.1（可配置）
- 稀缺度采用 Sigmoid 平滑：发表时越稀缺，`scarcity_weight` 越接近上限（默认 1.3）
- 默认关闭全论文一致性门控（`global_consistency_gate_mode=off`，可切换 `legacy_ratio|residual_soft`）
- 默认按 `object_verb_weight_mode=blended` 聚合同 object 的动词权重（抑制 `max-verb` 膨胀）
- 默认 `adoption_norm_mode=global_zscore`（跨年可比）；可回退 `yearly_percentile`，且年度百分位默认 `mid` tie 规则
- V6.1 输出语义纠偏：新增 `diffusion_impact`、`impact_score_semantic`、`impact_channels`；兼容保留 `impact_score`
- V6.2 文本并行通道：新增 `foundation_utility_raw` 与 `foundation_utility_norm`（基于 `top_objects` 的持续性/提及强度/概念广度组合，不使用引用数据）
- 新增实验性 `concept-year` 归因开关（默认关闭）：同年同概念按 `s_peak` 相对份额分配贡献，并输出 `leader/co_leader/follower` 标签
- 提供 A/B 对比输出能力：`scripts/legacy/validation/validate_impact_v6.py --compare-prefix-a ... --compare-prefix-b ...`
- 提供 V6.1 可行性三门禁自动报告：`validate_impact_v6.py` 默认输出零值堆积/样本对分差/跨年稳定诊断（可通过 `--gate-*` 参数调节）
- 提供 V6.2 通道可追溯检查：`validate_impact_v6.py` 输出 `Channel Traceability Check`
- 提供主分切换评估工具：`scripts/legacy/validation/evaluate_primary_channel_switch.py`（用于评估 `foundation_utility` / `method_transferability` / `blend_v1`，默认不切换主分；支持 `--progress` 与 `--resume` 断点续传）
- 与创新度共享 `object_core/task_core`、动词权重锚点配置、论文类型后处理

对应实现：

- `scripts/pipeline/calculate_impact_v6.py`
- `scripts/legacy/validation/validate_impact_v6.py`
- `scripts/legacy/validation/evaluate_primary_channel_switch.py`

## V5 保留信息（历史方案）

- IU 从 `task × object` 改为 `object`
- task 不再用于匹配，只作为权重因子
- 聚合采用 Top-3，降低 RPU 数量偏倚
- 双信号：`Diffusion` + `Persistence`
- 最终：`impact_score = diffusion_norm × persistence_gate`

- `scripts/legacy/validation/validate_impact_v2.py`
