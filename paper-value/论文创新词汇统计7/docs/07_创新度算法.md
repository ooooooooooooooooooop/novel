# 创新度算法（V2）

> 来源：`INNOVATION_V2_DESIGN.md`

## 核心定义

不直接学习“创新”，而是建模“常规学术空间”；创新信号定义为偏离常规结构的残差。

## 主流程

1. 从 RPU 提取 6 维特征
2. 用历史数据拟合 PCA 常规空间
3. 计算残差并施加“创新方向”约束
4. 年度内做百分位归一化
5. 与 `s_peak/s_synergy/s_bonus` 融合得到总分

## 关键模块

- `TaskIDFTracker`
- `FeatureExtractor`
- `RegularSpaceModel`
- `SignalCombiner`

## 关键点

- 创新是时间相对概念（按年份锚定）
- 通过方向向量抑制“非创新偏离”
- 使用 Count-Min Sketch 控制内存

## 输出关注字段

- `innovation_magnitude`
- `score_v2`
- `total_score_v2`
- `v2_degraded`
