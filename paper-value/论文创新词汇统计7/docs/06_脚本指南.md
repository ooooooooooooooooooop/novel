# 脚本指南

> 目标读者：日常运行与维护脚本的开发者

## 核心流水线脚本

| 脚本 | 用途 | 常用参数 |
|---|---|---|
| `scripts/pipeline/run_v2_full.py` | 创新度全量运行 | `--resume`, `--years`, `--warmup-to`, `--dry-run` |
| `scripts/pipeline/calculate_impact_v2.py` | 影响力计算 | `--pass`, `--year`, `--years`, `--force`, `--resume` |
| `scripts/pipeline/merge_signals.py` | 合并创新+影响结果 | `--year`, `--years` |
| `scripts/analyze/analyze_distributions.py` | 分布与正交性分析 | `--sample` |
| `scripts/analyze/analyze_trends.py` | 趋势与角色演化分析 | 默认全量 |

说明：以上脚本均支持 `--config <json>` 指定配置文件。
说明：主链路已统一为 `scripts/` 下 canonical 路径，根目录不再保留兼容启动器。

## Legacy 脚本（非默认）

- `scripts/legacy/calculate_impact_v2_lowmem.py`：低内存场景专用。

## 维护建议

- 新增脚本前先归类到：pipeline/query/validate/analyze/train。
- 新增参数时保持与现有命名风格一致，并补齐 `--help`。
- 环境自检可执行：`tools/health_check.ps1`。
- 主链路运行示例：
  - `python scripts/pipeline/run_v2_full.py --dry-run`
  - `python scripts/pipeline/calculate_impact_v2.py --pass 0`
  - `python scripts/pipeline/merge_signals.py --years 2010-2025`
  - `python scripts/query/query_paper.py --title "transformer" --year 2020 --top 20`
