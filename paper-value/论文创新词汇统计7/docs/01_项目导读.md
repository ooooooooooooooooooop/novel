# 项目导读（重构前）

> 目标读者：准备接手/整理该项目的开发者
> 更新时间：2026-02-09

## 1. 这个项目在做什么

项目目标：从 2010-2025 年论文中抽取研究行为单元（RPU），分别计算 `innovation_score`（创新性）和 `impact_score`（影响力），再按年度阈值划分四类角色：`Pioneer / Ahead-of-time / Diffuser / Routine`。

核心方法分离：
- Innovation：发表时刻的“领先性”（是否偏离常规学术空间）
- Impact：发表后的“被采纳程度”（扩散广度 x 持续性）

## 2. 当前稳定流程（已完成 Phase 1-5）

1. RPU 抽取：`rpu_full_extraction_deberta.py`
2. 抽象层构建：`mine_phrases.py` + `normalize_cores.py` + `apply_abstract_layer.py`
3. 创新度计算（V2）：`scripts/pipeline/run_v2_full.py` / `scripts/pipeline/calculate_innovation.py`
4. 影响力计算（V5）：`scripts/pipeline/calculate_impact_v2.py`
5. 结果整合：`scripts/pipeline/merge_signals.py`
6. 分析可视化：`scripts/analyze/analyze_distributions.py` + `scripts/analyze/analyze_trends.py`

## 3. 数据与产物主路径

- 输入库：`paths.rpu_db_path`
- 创新结果：`paths.innovation_output_dir/innovation_v2_{year}.jsonl`
- 影响结果：`paths.impact_output_dir/impact_final_{year}.jsonl`
- 合并结果：`paths.paper_signals_output_dir/paper_signals_{year}.jsonl`
- 分析图表：`paths.analysis_output_dir/*.png`

## 4. 目录体量（用于整理优先级）

当前大目录体量（约）：
- `rpu_db_dir/` 108.99 GB
- `impact_output_dir/` 102.85 GB
- `innovation_output_dir/` 18.48 GB
- `artifacts/archives/_archived_srl_ner_pipeline/` 14.34 GB
- `paper_signals_output_dir/` 9.97 GB

结论：重构应优先“代码与文档结构”，不要先迁移大体量数据目录。

## 5. 先理解后重构的关键事实

- 根目录有 34 个脚本，职责混合（计算、验证、查询、可视化、训练）。
- 多个脚本包含硬编码绝对路径（`<PROJECT_ROOT>\...`）。
- 影响力计算存在多版本实现：`scripts/pipeline/calculate_impact_v2.py`、`scripts/legacy/calculate_impact_v2_lowmem.py`、`scripts/legacy/calculate_impact_v2_optimized.py`。
- `TODO_execution_plan.md` 是当前最完整的运行历史与状态来源。

## 6. 后续整理建议（文档阶段完成后）

1. 先统一配置入口（路径、年份范围、输出目录）。
2. 再做脚本分层（pipeline/query/validate/analyze/train）。
3. 最后处理历史兼容入口（若存在）并统一到 canonical 路径。
