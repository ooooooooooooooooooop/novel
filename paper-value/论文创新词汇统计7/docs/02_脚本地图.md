# 脚本地图（重构前）

> 目标读者：需要快速定位脚本职责的开发者

## 1. 端到端主链路（推荐入口）

- 创新全量运行：`python scripts/pipeline/run_v2_full.py --dry-run`
- 影响力计算：`python scripts/pipeline/calculate_impact_v2.py --pass 0`
- 结果合并：`python scripts/pipeline/merge_signals.py --years 2010-2025`
- 论文查询：`python scripts/query/query_paper.py --title "transformer" --year 2020 --top 20`
- 分析图表：`python scripts/analyze/analyze_distributions.py` / `python scripts/analyze/analyze_trends.py`

## 4. 重构前注意事项

- 多脚本使用绝对路径；直接移动文件会导致运行失败。
- 先补统一配置层，再做目录迁移。
- 优先保持 canonical CLI 的参数名和默认行为稳定。
