## 五、文档规范

### 5.1 命名规范

- 使用中文文件名（便于识别）
- 使用数字前缀排序（01_, 02_, ...）
- 统一使用 `.md` 扩展名

### 5.2 格式规范

- 标题层级：最多3级（#, ##, ###）
- 代码块：指定语言（python, bash, json, sql）
- 表格：用于结构化信息
- 链接：使用相对路径

### 5.3 内容规范

- 每个文档开头说明目标读者
- 代码示例可直接运行
- 重要信息用表格或列表
- 复杂概念配图说明

### 5.4 维护规范

- README.md 保持简洁，变动少
- 开发日志持续更新
- 算法文档版本变更时更新
- 数据格式文档随输出变化更新
