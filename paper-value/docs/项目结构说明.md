## 四、数据流概览（与 .kiro/steering/structure.md 一致）

1. **输入**：CSV 论文元数据与文本 → RPU 抽取（摘要/标题）→ 写入 SQLite 等。
2. **核心**：历史状态（含 checkpoint）→ 创新/影响力信号计算 → 输出 JSONL 等。
3. **训练**：Excel 训练数据 → 各 `train_*.py` → 检查点存于 `models/cached_models/`，由 `validate_*` / `check_*` 做质量与稳定性校验。

---

## 五、命名与入口速查

- **主入口/全流程**：根目录 `main.py`；阶段 7 全流程 `论文创新词汇统计7/run_v2_full.py`。
- **创新计算**：根目录与 `论文创新词汇统计7/` 下均有 `calculate_innovation.py`，以 7 下为当前主实现。
- **RPU 抽取**：`rpu_*`（主用 `rpu_full_extraction_deberta.py`）；训练类 `train_*`；校验类 `check_*` / `verify_*` / `validate_*`。
- **版本化脚本**：`论文创新词汇统计[N]_[功能].py`，数字 N 表示阶段/版本。

以上即为当前项目的整体结构梳理；具体单脚本职责以代码与各 DESIGN/README 为准。
