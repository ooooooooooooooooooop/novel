## 如何执行整理（移动脚本）

脚本已按阶段归入各子目录。若今后有类似脚本需移入，在项目**根目录**下按下面方式手动移动即可。

### 手动逐条移动（PowerShell）

在项目根目录打开 PowerShell，执行：

```powershell
# 阶段1-4
Move-Item "论文创新词汇统计.py" "历史版本\阶段1-4\"
Move-Item "论文创新词汇统计1_单进程.py" "历史版本\阶段1-4\"
Move-Item "论文创新词汇统计2_模块重构.py" "历史版本\阶段1-4\"
Move-Item "论文创新词汇统计3_流式重构.py" "历史版本\阶段1-4\"
Move-Item "论文创新词汇统计4_分词重构（统计语言学+困惑度评估）.py" "历史版本\阶段1-4\"

# 阶段5
Move-Item "论文创新词汇统计5_1概念共现网络 + 知识图谱.py" "历史版本\阶段5\"
Move-Item "论文创新词汇统计5_2构建共现网络.py" "历史版本\阶段5\"
Move-Item "论文创新词汇统计5_3语义关系抽取.py" "历史版本\阶段5\"

# 阶段6
Move-Item "论文创新词汇统计6_1_1词库统计.py" "历史版本\阶段6\"
Move-Item "论文创新词汇统计6_1_2词库统计.py" "历史版本\阶段6\"
Move-Item "论文创新词汇统计6_2观点识别.py" "历史版本\阶段6\"
Move-Item "论文创新词汇统计6_2_1观点识别.py" "历史版本\阶段6\"
Move-Item "论文创新词汇统计6_2_2观点识别.py" "历史版本\阶段6\"
Move-Item "论文创新词汇统计6_2_3观点识别.py" "历史版本\阶段6\"
Move-Item "论文创新词汇统计6_2_4语义识别.py" "历史版本\阶段6\"
```

若尚未创建子目录，可先执行：

```powershell
New-Item -ItemType Directory -Force -Path "历史版本\阶段1-4", "历史版本\阶段5", "历史版本\阶段6"
```

再执行上面各 `Move-Item` 命令。  
（原一键脚本 `整理并移动脚本.ps1`、`_do_move.py`、`moves.txt` 已作为临时文件删除，不再保留。）
