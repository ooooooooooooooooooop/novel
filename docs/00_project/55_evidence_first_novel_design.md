## 1. 本轮确定的方向

用户最新要求：对于消耗大量时间或 token 的研究，先测试再投入。由此调整上一轮“约十二周、先做原创中篇”的排期：不预先承诺大规模研究，先检验最可能改变下一步决策的问题。

- 目标：在已有工程基础上，验证系统能否让人物选择产生持续后果，并在明确资源投入下改善故事。
- 第一交付：收尾既有研究并确认可复用证据，再补能够判断“继续、修正或放弃”的最小缺口。
- 首部原创 3—5 万字作品仍是远期建议，尚未锁定为用户验收目标。原创、长篇连载、续写的优先级不妨碍先完成共同的证据和小试设计。
- 自主运行、创作增益、读者价值分别记录。机器偏好只支持机器评价下的结论，不自动证明真人阅读价值。
- 保留零人工生产和研究流程方向；本阶段不安排人工填响应、人工盲评、人工逐章放行或读者招募。

### 1.3 执行顺序与汇合条件

1. **质量线先完成可恢复的离线收尾。** 重算、来源复用判定和可恢复用量已完成；完整成本未知之处显式保留，不无限追账。由于留出与成本前提未成立，当前不再把整组独立复判或 123 份评审列为下一笔优先投入。若后续有具体诊断问题，只评能改变决定的最小子集并保留开发标签。
2. **State 线完成实验接入后，保持独立验证。** 先前仅有受控接口样例，现已补入 §1.5 的研究入口及两组开发提示；生产入口不自动启用该实验。新生成只检验一个主要问题，例如“固定其余条件后，经过选择的上下文是否优于直接注入状态”；错误状态、过载状态等对照按具体疑点加入后续小试。
3. **再检验两条线的组合。** 质量策略先固定一个候选，不把规划、搜索、修订全部交叉展开。比较简单基线、仅质量策略、仅状态选择、两者组合，分别测主效应和相互影响。
4. **由结果决定留下什么。** 组合值得投入才进入各自滚动的三章窗口；若仅一项有效，保留该项；若组合抵消，分开使用或收缩；若证据仍不明确，停止扩样并记录适用范围未知。

四种条件都保留必要事实、人物认知边界和现有提交保障。“仅质量策略”不意味着失去基本记忆，“仅状态选择”也不能偷偷增加规划或修订。各臂从同一起点分叉，此后独立更新正文和状态。

不要求两条线先各自达到统计显著才允许测组合：有明确机制理由时，可做预算有限的相互影响小试。但数据不可信、状态污染或未守住硬边界不能靠组合得分掩盖。四臂试验须单独制定调用与评估预算，不套用下文两臂 20 次上限后暗中扩充。

四种条件用于区分机制。若结果只有成对偏好、没有共同量尺，就报告预先固定的具体对局；不能把不同对局的胜率直接相减，冒充定量交互效应。

旧实验的提示、分组、留出和判据继续冻结。统一的是证据和成本的报告接口，不把 State 接入正在收尾的质量实验，不用新判据追溯宣布旧实验通过；新增或修改的实验另开协议版本。

### 1.27 拆分披露判断与事实支持，冻结成对开发对照（2026-09-08）

针对 §1.26 的两项分歧，将可见性契约明确为“执行作者输入后，是否会向读者确认隐藏条目的完整命题或揭示其对象”。三个判断分别解释：

| 判断 | 所回答的问题 | 不应推出的结论 |
|---|---|---|
| 披露相容性 | 指令执行后是否披露秘密；对象或范围是否足以判断 | compatible 不证明隐藏条目为真，也不批准状态提交 |
| 事实支持 | 来源是否支持命题，尤其是全称或绝对断言 | 缺少支持不自动代表本次写作会披露它 |
| 条目具体性 | 是否给出了可追踪的秘密值或对象 | 缺少具体值不自动使明确无关的动作变成泄露 |

研究评审只负责第一项。完整命题的一部分出现不能直接计作完整披露，多条陈述组合足以推出完整命题则仍拒绝。请求披露但指代或范围不明仍用 inconclusive；不因没有找到冲突而自动放行。结果和研究交接明确标记 `fact_support_evaluated=false`，生产事实与状态门禁不变。

新增 `visibility_controls --suite scope` 的 4 个中性样例组成两对：来源缺口下的不解释来源动作／要求解释未知来源；仅提旧安排／明确披露旧安排未入任何正式档案。预期标签随新样例预先冻结，不改写旧 v03、v09 的标签或历史成绩；旧套件清单和计分输出将两项列为 `disputed_legacy_labels`，不作为当前口径的可靠真值。

重要遗漏修复：原 review_id 只绑定候选和作者提示，规则变化后旧响应仍可能具有相同 ID。现在把评审规则哈希纳入 review_id，解析时核对当前规则，研究交接携带规则哈希；旧规则响应必须重新生成，不能在新语义下自动沿用。历史包保持原样。85 项相关测试通过，包括同一载荷改变规则后拒绝旧响应、两类交接标记和新套件计分。

## 3. 小说生成的核心设计

### 3.1 三类信息必须分开

| 信息 | 含义 | 何时允许更新 |
|---|---|---|
| 已提交事实 | 正式正文和状态中已经发生的事件，附来源和时间 | 经现有提交边界验证后 |
| 解释与预测 | 对人物动机、潜在后果、读者预期的推断 | 可修正；不能直接覆盖事实 |
| 未来计划 | 下一场景或故事弧的候选发展 | 由实际结果触发调整；未实现前不成为历史 |

候选探索使用隔离状态。未选方案的事件、人物获知的信息和预测结局不得写入正式记忆。回看一个选择的后果，必须引用选择之后实际提交的证据；预测自洽不算兑现。

### 3.2 决策循环

1. 读取已提交状态、当前位置及相关正文证据。
2. 从已有候选池获得与当前场景自然相连的材料。
3. 按冻结策略选择直接生成、自由规划、候选搜索或定向修订。
4. 生成草稿，在分支内检查事实、人物认知、因果和文本缺陷。
5. 使用现行模式的门禁提交；记录被选方案和实际变化。
6. 依据实际变化更新未来计划和后果记录，然后进入下一单元。

作品层保留承诺和可能结局，故事弧层维护压力与未处理后果，场景层组织眼前行动。近期计划具体，远期计划可变。规划负责提供可能性，不要求每章完成宏观清单。

安静场景可以改变信任、认知或读者预期，也可以作为有效单元中的氛围节拍；不要求每段都产生外部事件。现有 PlotUnit 的有效性定义不在本轮改动。

### 3.3 何时增加计算

先比较固定策略，再研究按情境分配计算。否则无法分清收益来自规划内容、更多尝试还是触发策略。

- 事实矛盾有明确证据时，可在授权策略和预算内进行定向修复。
- 不可逆选择、多个可行方向或未明后果，是研究候选搜索的情境，不是强制多调用的理由。
- 模糊审美分歧不触发无限改稿。新研究协议预先固定修订次数和接受／保留／停止规则。
- 门禁未通过与作品质量不佳分别记录。本设计不放松当前生产硬门禁，也不把研究观察直接变成生产放行。
- 后续接口实现仍保持现有关闭／缺省时的零成本契约，不能使未启用实验的提示、状态或产物发生变化。

## 4. 小试路线与投入上限

本节仅用于第 1 节接续后仍需新增证据的缺口，不要求已有实验重走 T0—T4；已有三章窗口不退回单章生成。T0 和可恢复的 T1 工作已在本轮完成，缺失收据继续明确保留。

每项小试开始前，用一页记录问题、唯一主要差异、材料、预算上限、可观察结果和下一步决策。预算记录不是调用授权；执行仍使用适用的已授权模型、数据范围和模式政策。

| 步骤 | 最小动作 | 停止或继续条件 |
|---|---|---|
| T0：已有证据检查 | 读取协议、定位结果与实际产物目录、调用纯函数检查输出语义；新增模型调用为 0 | 有可重算旧结果则复用；缺失则标明检索范围，不因单一命名路径缺失宣布实验不存在 |
| T1：离线适配 | 在已有记录上还原材料来源、原始判断和完整用量；不生成新正文 | 若无法还原，明确哪些比较不可用；不用猜测补值，不无限搜索或重建整条历史链 |
| T2：最小方向试验 | 只比较 2 个策略、2 个来自不同来源组的短单元；每策略每单元至多 3 次生成／选择／修订调用 | 一次小试总计最多 20 次模型调用；无清楚增益则不扩大。正向只允许进入窗口试验 |
| T3：连续窗口试验 | 候选和基线各自延续自己的 3 章历史；检验选择后果能否持续 | 调用预算在 T2 报告后另行估算和冻结，不沿用单章预算直接扩展 |
| T4：较大验证 | 新材料、足够独立来源、冻结方案，检验收益和适用范围 | 只有窗口结果值得投入才制定样本量；不按先前十二周排期自动启动 |

T2 的 20 次为设计上限：最多 12 次生产侧调用，加 4 次正文 A/B 与 B/A 评估、4 次机械对照评估。额外裁判、重试或校准不能偷偷加在上限之外；需要更多时先缩小方案或留给独立后续试验。

总调用数之外，还必须冻结总输入／输出 token、可见推理用量、货币成本及最长执行时间的上限。具体数值按实际模型、上下文长度和现有预算政策填写；字段不全时保留为设计，不启动调用。不能为了满足次数上限而放开单次消耗。

T2 只测两臂，避免一开始铺开所有模块。基线使用已有证据最强、成本可承受的简单策略；挑战者只改变一个策略或状态选择机制。先完成 T1 再选，不默认全部值得重做，也不重启已经否定的旧锚定方案。

T2 的继续条件：管线、成本和对照均有效；两个来源的信号同向，且未出现明确一致性退步，才值得进入 T3。混合结果记为不确定，分析是否存在可离线解决的原因；不通过反复补样凑胜利。这是资源筛选条件，不是统计显著性或质量晋升标准。

## 5. 成本与证据的最小契约

以下为研究记录，不新增核心叙事对象。优先给现有 JSON 记录增加适配输出，保留原文件不变。

| 记录 | 必需信息 | 明确不代表什么 |
|---|---|---|
| 实验规格 | 假设、两臂差异、版本、来源划分、预算、主比较、退出规则、冻结时间 | 不代表运行已获授权或结论已成立 |
| 材料与曝光 | 内容哈希、来源组、前缀与派生链、历史用途、首次曝光、独立单元 | 改名、换章节或重复生成不自动成为新作品 |
| 调用收据 | 所属臂、角色、请求与实际模型、输入输出哈希、用量、成本、耗时、结果 | 请求模型名不等于已核实实际模型身份 |
| 成对观察 | 原始 A/B 与 B/A、稳定胜负、平局、位置敏感、弃权、技术无效原因 | 裁判多数或稳定判断不等于真人真值 |

硬事实字段来自文件、调用收据或已提交正文；解释字段包括评审理由与效果归因；运行状态包括 pending／done／failed。缺失记为缺失，不能用估算值冒充调用事实。

最终评估使用与 writer 不同的已授权模型族、独立上下文，只读取任务约束与正文，不读取生成计划、内部选择评分或期望结论。同族结果只算诊断；策略内部 selector 的判断不能充当独立效果证据。裁判不可用时先保留产物，不擅自新增模型或修改冻结协议。

### 5.1 完整成本

比较“同预算下哪个策略更好”，预先固定预算上限；报告各臂实际消耗，不为了凑齐 token 强迫模型写更长规划。

- 生产成本包含规划、草稿、选择、修订、被丢弃候选、失败尝试、上下文重读及缓存成本。
- 离线最终评估成本单列，同时进入研究总预算。搜索策略内部的 selector 计入该策略生产成本。
- 输出 token 只是诊断维度，不能替代总 token、总费用或时间。
- 若模型不提供完整计费／推理用量，记录不确定性；只能声称可观察用量下的比较。
- 任何改口径都创建新版本。看过结果后改变分母或成本定义，不继续保留原确证性标签。

### 5.2 平局、缺失和独立性

换位后两次都选同一文本，记稳定胜或负；两次都无差别，记稳定平局；偏好随位置改变，记位置敏感；不确定和技术无效另列。

同时报告所有分母：计划单元数、完成数、技术有效数、稳定胜负数、平局数、弃权及位置敏感数。条件胜率 `W/(W+L)` 仅作辅助，分母为零时记未定义；另报告 `W/N`、`L/N`、`(W-L)/N` 及各类占比，其中 N 为技术有效观察总数。不得隐藏生成失败；作品完成率单独以计划单元为分母。

镜像判断、重复生成及同作品多章不当作独立作品。窗口保持真实章节顺序，仅遮蔽来源与实验臂标签；确认性推断按来源作品／故事种子组聚类。两个来源的小试不能估计跨作品普遍效果。

两臂从同一输入分叉，之后各用自己的正文和状态；不得让基线读取挑战者的更好记忆。局部同一起点试验与各自滚动的窗口试验分别报告。

## 6. 已做的零调用检查与修正

2026-09-07，本轮检查得到：

1. 本地既有算力协议把主口径从总 provider token 改为额外 completion token。它们不是同一个成本问题；单凭协议无法确认等成本下的质量排序。

3. 对 `resolve_pair` 进行三次纯函数调用：稳定胜得到胜者；位置敏感和稳定平局均得到无稳定胜者。这适合生产选稿的现有含义，但研究汇总须读取原始判断，不能把两种原因混为一类。

| [WritingBench](https://arxiv.org/abs/2503.05244) | 按写作任务设置评价维度 | 可参考评价组织方式，不用通用写作分数替代连续故事的后果和收束检查 |
| [NIST，两水平全析因设计](https://www.itl.nist.gov/div898/handbook/pri/section3/pri3331.htm) | 同时安排因素组合，区分主效应与交互；重复次数另外计入 | 本轮接续设计后补查；采用质量策略×状态选择的四种条件，不凭单项试验推断组合收益，预算包含全部重复与评估 |
| [scikit-learn，数据泄漏指南](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage) | 测试资料不参与模型或方案选择，分离开发与最终评估 | 第二轮据此检查跨战役曝光；复用的是隔离原则，本项目涉及提示／策略开发，不据此宣称模型重新训练或量化了泄漏影响 |
| [W3C Web Annotation，文本引用与位置选择器](https://www.w3.org/TR/annotation-model/#text-quote-selector) | 用精确文本与位置定位来源片段 | 研究入口复用“引文＋位置”的思路并绑定来源哈希；无需新建知识图谱。采用原始解码文本的字符位置，不宣称实现完整 W3C 格式或语义真实性验证 |

复用结论：保留本地已有模型与接口，借鉴研究设计；本轮不安装新框架。尚需实证的差异是：可审计的选择后果管理，在完整成本受限时能否优于简单基线。

## 8. 可能改变下一步的重要遗漏

- **记忆是否可信，比记忆是否丰富更早决定效果。** 错误提取会让系统严格维护错误事实。小试必须抽查状态与其正文证据是否对应，不能只测状态之间是否一致。
- **小试正向不等于长篇正向。** 限定小试用途为排除明显失败和决定下一笔投入；仍需各自滚动的窗口验证。
- **选稿函数不等于研究统计器。** 本轮已观察到平局分类差异，先适配原始观察，再谈胜率。
- **预算定义会改变优胜者。** 计入重读、选择和废稿成本；成本不明时不选“最划算”策略。
- **新样本标签不保证独立。** 追踪作品和派生链；模型预训练中是否见过公开原作通常未知，故原创与既有作品续写的结果分层解释。
- **安静场景可能被误判为停滞。** 关系、认知和预期变化允许构成有效推进；不靠增加宏观任务数量修复所有低分。
- **冻结后仍可看见最终验证材料，会让研究继续过拟合。** 材料曝光需要记录；测试过的材料回到开发用途，新结论使用未参与选择的新材料。
- **两项机制可能互相破坏。** MTB 的主线约束可能把 State 选择层压下的线程重新塞回正文；过强抑制也可能删除因果必需信息。新组合实验中，章内规划和修订只消费允许进入本章的上下文包及必要约束，不能经 scratchpad 把防火墙隔离的信息绕回正文。
- **选择不同于原作，不等于选择错误。** M6 的原作线程覆盖率只作诊断；后续评价同时允许合理的新路径，否则会把“照原作复现”错误地优化成目标。
- **新增方案会挤掉已经接近完成的研究。** 每次调整路线必须列出旧线保留、收尾、暂缓、终止的具体工作；本轮已据此把旧线接续置于新试验之前。
- **工程组件存在，不代表真实运行用到了它。** 测试手工传入一个干净字符串，不能证明生产入口经过了来源核验、候选选择和防火墙。先记录实际入口调用和最终提示，防止花费模型预算比较两个实际上未启用目标机制的条件。

这些遗漏将第一优先级确定为“已有证据能否可靠支持一次小决策”。只有这个检查可用，才值得为下一次模型实验投入更多时间和 token。
