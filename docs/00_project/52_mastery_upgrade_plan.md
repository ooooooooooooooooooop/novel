## 0. 定位

```text

+ 多层质量评价
```

本轮**不声称已实现大神级**。完成后只能证明：系统具备向该目标迭代的正确架构、更强的叙事搜索与评价能力、可验证可回滚可长期实验的工程基础。是否达大神级由系统外隐藏来源人类长期阅读实验验证。

## 2. P1 长程因果防线

把系统从「检测局部事实矛盾」升级为「阻止已发生现实、已付代价、已形成成长被后文悄悄抹掉」。必须覆盖 5 类失败模式：

1. 已完成事件被重写（已摧毁地点重新完好 / 已公开信息重新变秘密 / 已完成行动当作从未发生 / 已确认身份重新悬空）
2. 已付代价失效（失去资源无解释恢复 / 能力副作用消失 / 代价不传播 / 只有即时收益无持续成本）
3. 人物成长或知识状态重置（学会的能力重新不会 / 已接受事实重新不知道 / 关系变化恢复原状 / 关键转变后回默认性格）
4. 制度与群体后果未传播（法令/战争/资源变化只影响场景 / 权力结构改变不影响其他角色策略 / 重大公开事件未进入社会层）
5. 已有选择未改变后续策略空间（删除所谓重大选择后未来完全不变 → 质量信号）

实施原则：
- 硬事实类问题优先确定性检测；证据来自已提交正文与可信状态；草稿不得污染长期状态。
- 检测带证据锚点；判定顺序无关；重复运行幂等；不用 LLM 裁判替代可确定判断。
- 每个失败模式至少：一个违规注入 + 一个干净负控制 + 一个边界样本 + 一个顺序变化样本 + 一个幂等样本。
- 接入正式章节提交前的硬门禁链（flow v3 提交点）。

验收：所有新增对抗样本被阻断；负控制不误伤；三流/Q1 不回归；违规不推进 Frame/状态/章节号；失败后无半提交。

## 3. P2 Narrative Orchestrator

独立全局叙事编排层，回答「在所有仍合法内容中，为什么现在最值得写这一部分」。不写正文、不保存全部事实。

必需编排状态概念：
- Reader Expectation（等什么/从哪章开始等/强度/部分回答/过久/兑现改变什么）
- Promise/Payoff Debt（与 ForeshadowGraph 关系明确：graph 记录线程事实，Orchestrator 判当前读者优先级）
- Relationship Trajectory（方向/近几章变化/停滞/重复互动/下一次变化需什么事件；不得折成好感度数值）
- Emotional Pattern（主情绪/变化方式/强度/连续同质/靠自我说明；只防重复，不强制反转）
- Thread Rotation（最近出场/离场角色世界存在感/离开太久/是否强行平均轮转）
- Chapter Function（积累/兑现/转向/选择/后果/关系变化/信息重构/留白；禁止每章全承担）
- Information & Scene Density（解释/场景/对话/行动密度、揭示量、连续同构；只判持续同质化和明显失衡）

输出（须进入 Candidate Pool → Narrative Selector → Chapter Packet，不得绕过 Suppressor 与 Context Firewall）：
- 优先推进事项 / 建议暂缓事项 / 必须保留的沉默 / 可兑现承诺 / 不应主动提及的信息 / 关系变化机会 / 主要章节功能 / 风险提示

关键约束：
- 只能读已提交状态；不得把所有活跃线程列入本章；不得因伏笔存在就强迫提及；不得生成正文句子；不得把编排状态写成 prompt checklist；编排信息为空时不增加 prompt 段落；关闭功能时保持旧 prompt 合同。

验收：
- Orchestrator 有生产调用方；输出被 Candidate Pool 和 Selector 实际消费；能改变候选优先级；不强迫增加线程；无编排状态时零成本降级；新旧流程测试通过。
- 关键验证样本：同一伏笔刚出现 vs 已等十章；同一人物刚离场 vs 长期被遗忘；同一情绪首次 vs 连续五章重复；同一信息读者已知 vs 未知——事实状态相同但编排历史不同 → 优先级不同。

## 4. P3 章节级多尺度叙事搜索

在生成正文前搜索多个**结构上真正不同**的章节未来，并经短期 state rollout 判断后果。

- 候选表示：主要行动者 / 核心选择 / 阻力来源 / 代价 / 状态变化 / 关系变化 / 信息揭示 / 读者预期变化 / 对未来 3–5 章影响 / 主要风险。
- 结构异质性门禁：候选间至少在行动主体/选择/代价/因果后果/关系轨迹/揭示时机/章节功能之一有实质分叉；实现结构近重复检测，近重复不得伪装多样性。
- 搜索顺序：生成结构候选 → 硬事实合法性 → ReaderContract/Creative Constitution 约束 → Orchestrator 适配性 → 3–5 章状态级 rollout → Pareto 前沿 → 选择进入正文。
- Pareto 选择：至少独立保留因果价值/人物价值/读者动力/作品契合度/原创性/长期可持续性/风险独立维度，禁止加权单总分；高分歧候选不立即淘汰（可加 rollout / 结构变体 / 延迟裁决）。
- Candidate Precommit：看到候选正文前冻结本轮选择依据（本章最重要问题/必须看到的后果/哪种漂亮表达不能掩盖结构失败/什么情况推翻当前偏好），复用 EvaluatorPrecommit 思路。
- 正文生成边界：只对最终保留的少量候选生成正文；正文不得改核心选择/代价/状态变化/允许揭示信息；正文实现失败回到该候选的正文修订而非偷偷换剧情。
- 接入：compose / extend；audit 只识别评价不承担候选生成。

验收：候选非语言近似；rollout 能改变选择；即时刺激强但破坏后续被识别为风险；较慢但后果更强的候选保留在 Pareto 前沿；关闭搜索旧流程不变；选中候选才事务提交；未选候选不污染正式状态。

## 5. P4 Taste Stack 换轨

把分散评价工具整理成职责清晰、证据可聚合、不制造虚假确定性的五层体系。

1. **确定性硬门禁**：事实/时间/状态/信息权限/世界规则/ReaderContract/重复/已发生现实/已付代价/提交完整性。只证明「无已知硬错误」。
2. **专门轴评价**：可扩展轴接口；通用轴（人物选择/场景实现/情绪落地/关系变化/承诺兑现/读者动力/模板化）+ 作品特有轴（Creative Constitution/WorkModel/AuthorModel/ReaderContract/真实作品诊断）。每个轴：看候选前冻结标准、说明所需正文证据、允许 unreviewable、不用自报 confidence 直接定权重；禁止统一 checklist 套所有小说。
3. **Blind Eval**：隐藏版本来源、A/B 与 B/A 换位、长度差异记录、允许弃权、证据锚点、多裁判分开保存、统计裁判相关偏差、不用简单多数制造确定性、输出分轴相对改善 + Wilson 区间。回答「修改后是否相对变好」，不回答「是否足够好」。
4. **PASS Audit**：route=pass 独立抽样、不暴露原 Review 结论、区分 any/actionable/blocking miss、按审核版本和时间 cohort、报告 severity disagreement、不改历史结果只是影响未来。回答「Review 漏了多少」。
5. **人类隐藏来源验证**：材料包生成/随机编号/来源隐藏/原文+系统版+基线混排/读者匿名/单章/三章/十章/三十章/专业+普通读者分组/「哪版更好」与「愿不愿继续读」分开/允许无差异/记录放弃位置/记录原因不强迫统一 rubric/作者、作品、题材、时间分割/永久 holdout。工具协议完整；无真人数据 → `not_run`，不生成假结果。

G7 处理：保留历史实现与证据；从大神级路线图退役；不再作为项目总发布门；文档与 CLI 帮助中明确研究性质；不删除命令；不修改历史失败结果。

统一质量报告：硬门禁状态 / Blind Eval 相对改善 / PASS Audit 漏检率 / Style Drift / 人类盲评状态 / 未武装能力 / 证据时间与版本。**禁止输出「最终大神分数」。**

验收：Blind Eval 与 PASS Audit 有稳定 CLI 与 schema；能聚合到统一报告；未资格化裁判不阻止正式提交；人类验证无数据诚实显示未运行；G7 状态与主线不冲突；现有 A/B、audit-pass、drift 测试不回归。

## 6. P5 AuthorModel V3

把 AuthorKernel 从「作者原则摘要」升级为「能基于历史选择、反例和后果，预测作者在新情境中更可能保留什么方案的决策先验」。

四层分离（不得混合）：StyleProfile（怎么表达）/ AuthorModel（作者如何选择）/ WorkModel（本作品如何组织）/ TasteModel（哪些偏离可能值得保留）。

AuthorModel 必须支持：
1. 选择证据（真实方案选择/修改前后/删除内容/ChoiceLedger/后续结果/多作品反复取舍；成稿只作弱证据）
2. 反例（每条原则：支持样本/反例/适用边界/置信度/最近更新/是否只属某作品；不得冻死为人格标签）
3. 后果回填（复用 Hindsight：选择时记录预测 → 若干章后记录真实后果 → 判断原则是否带来预期价值 → 更新原则）
4. 作者与作品分离（作者跨作品稳定原则 / 作品局部组织习惯 / 题材临时策略 / 当前章节局部需求）
5. 不确定性（未见情境输出多方向、标记证据不足、不得用弱 AuthorModel 强淘汰创新候选）
6. 跨作品验证（留一作品验证 / 作者开闭对照 / WorkModel 开闭对照 / Selection×Generation 2×2 归因 / 隐藏作品选择预测；不得只用「文字像不像作者」验收）

生产定位：先以 shadow / candidate prior / tie-break signal 接入；跨作品证据不足前不得成硬门禁。

验收：新反例更新旧原则；区分作者与单部作品；影响候选排序；影响来自决策而非词汇命中；隐藏作品验证无泄漏；作者关闭时流程可运行；私有语料不入 Git。

## 7. P6 世界因果与人物策略研究轨

独立研究轨，不直接升级生产强依赖。

1. **World Causal Compiler**：根规则 → 能力与资源边界 → 使用代价 → 制度 → 权力结构 → 群体利益 → 人物策略 → 冲突。
   - 与现有模块边界：WorldModel 存状态；FactLedger 存已确认事实；Compiler 推导规则改变的策略后果；Orchestrator 判断何时值得写。
   - 验证：规则删除测试（删规则后人物最优策略/制度/主要冲突是否变化，完全不变 → 装饰设定）；代价传播测试（能力代价传播至资源/身体/关系/权力/后续选择）；二阶后果测试（规则变化 → 群体行为改变 → 制度反应 → 角色策略改变）。
2. **Character Policy Engine**：人物行动提案接口（目标/恐惧/价值排序/错误信念/已知信息/关系债务/资源/当前压力/对他人的判断）；只提出行动/局部动机/预测他人反应/暴露信息不对称；不得让每个角色各自写正文；最终正文由统一叙事者生成。

接入纪律：初期只 isolated research flow；不默认注入 Tier 0/Q1；不产生真实作品强制依赖；规则删除/策略变化/真实候选改善均获证据后才提出生产接入建议。

## 8. P7 长程验证与恢复自动生产的条件

- 本地 Canary（不依赖真人）：合成中性夹具 + 私有真实作品 Canary 5–10 章（正文与证据 gitignored）；验证多章节结构搜索/rollout/Orchestrator 更新/正文生成/Reader Gate/提交/Hindsight/PASS Audit/Blind Eval。
- **90 章无人 Canary 前置条件（全部满足才允许恢复）**：
  1. P1 长程因果门禁完成；2. Orchestrator 进生产调用链；3. 章节级搜索真实改变候选；4. 结构异质性有证据；5. Blind Eval 稳定测相对改善；6. PASS Audit 漏检率冻结口径；7. 人类盲评协议冻结；8. 至少一轮真人连续阅读数据；9. Provider 身份与预算冻结；10. 旧发布证据不变。
- 真人数据不存在 → 不跑正式 90 章资格 Canary，输出 `long_run_not_authorized`，不降要求。

## 9. 对抗测试集合（贯穿 P1–P7）

每类攻击样本必须有干净负控制：
- 长程因果：已发生现实被抹除 / 代价消失 / 成长重置 / 制度后果不传播 / 选择无未来差异。
- 编排：伏笔刚出现却立刻兑现 / 等待过久 / 情绪连续重复 / 支线被遗忘 / 所有线程每章平均轮转 / 一章多功能 / 读者已知与人物已知混淆。
- 搜索：多候选实际近重复 / 风格差异冒充结构差异 / 即时刺激破坏长期 / 高分创新被总分淘汰 / 未选候选污染状态。
- 评价：裁判偏爱华丽/更短文本 / A/B 换位结论翻转 / 多裁判共享偏差 / 无证据高 confidence / 生成器针对模板作弊 / 删困难情节提高评分。
- AuthorModel：作者特征与作品特征混淆 / 关键词命中冒充语义 / 新反例无法更新旧原则 / 隐藏作品泄漏 / 强制拒绝创新候选。
