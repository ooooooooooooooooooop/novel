# 51. 观点记录：sol5.6 —— 终裁品味可实现性与全自动大神级路径

状态：研究观点（2026-08-16），与 50 号观点并列保留，供后续比较与裁决。

## 核心命题

「大神级品味不能被自动模仿」不成立。更准确的结论是：

- 品味可以被学习、迁移和部分外推；
- 当前真正没解决的，是如何定义「大神级」、防止生成器与裁判共同作弊，以及如何证明裁判在新流派、新文化和真正原创作品上仍然可靠。

## 对「三层墙」的裁决

### 1. 数据稀疏 —— 现实困难，不是能力上限

大神级偏好样本确实稀缺，但品味不只存在于口头评分里，也存在于行为与结果标签中：

- 作者保留/删除了哪些方案；
- 草稿如何修改；
- 哪些伏笔最终兑现；
- 哪些角色变化被允许；
- 哪些商业诱惑被拒绝；
- 哪些作品多年后被复读、模仿、跨文化传播。

实证（How Do Humans and LLMs Reason About Creativity?，2025）：模型对未见设计答案的原创性预测，无示例 r≈.60–.67，给三个评分示例后 r≈.74–.76；同实验普通人 r≈.44–.47。默会判断可以被学到。

### 2. 不可言说 —— 不等于不可学习

区分三类蒸馏：

- 规则蒸馏（让专家说出 rubric）：丢失默会知识；
- 行为蒸馏（学习专家在两个方案间的选择）：不需要先语言化；
- 结果蒸馏（学习作品长期留存/复读/影响）：不需要先语言化。

AuthorKernel 方向成立：从 ChoiceLedger 压缩作者反复表现的价值、禁忌与代价偏好，强于 persona prompt。但它目前只完成了「作者决策先验」，未覆盖：多方案排序、前所未见方案的判断更新、作者/读者/历史价值权衡、判断不确定性。

### 3. 自反性（模仿=奖励熟悉）—— 错误推导

混淆了两件事：语言模型学习文本分布 vs 奖励模型学习「什么样的偏离值得保留」。奖励函数完全可以学习「新颖性 × 语境适切性 × 叙事作用 × 因果后果」，而非只奖励「像训练集」。

实证（Death of the Novel(ty)，2025）：26 位职业作家评 2,514 表达——最高 n-gram 新颖度组约 91% 不判为有创意；低表面新颖度中仍存在创意；GPT-5 的新颖性判断又能预测部分专家偏好。「罕见≠好原创」，真正要学的是**生产性新颖**。

## 78% 不是硬上限

LitBench（EACL 2026）真实含义：73.1% / 78% 是特定模型对 Reddit r/WritingPrompts upvote 偏好（43,827 训练对 / 2,480 测试对）的一致率。它测量的是「能否预测特定 Reddit 社群的相对 upvote」，不测量职业作家/顶级编辑判断、跨文化价值、长期留存、「优秀 vs 时代级」区分。论文未声称 78% 是理论上限，更未测量大神级专家尾部。

- 「78% 是大神品味硬上限」→ 错误陈述。
- 「78% 说明当前公开文学监督信号很弱」→ 正确解释。
- 本项目 Gemini 0.427 / DeepSeek 0.5 只说明未通过当前 G7 协议，不推出自动品味不可实现。

## 三个真正的困难

1. **目标不可识别**：「大神级」不是单一天然标签，混合当代读者偏好、专业作者认可、范式开创、跨文化有效、长期生命力、对后人的影响。不应训单一「大神概率」分数，应预测向量：作者一致性、生产性原创、长程因果回报、情感后效、主题压缩力、读者黏性、专家偏好、跨群体迁移、不确定性。
2. **生成器与裁判共同 reward-hack**：实证（More Convincing, Not More Correct，2026）自博弈裁判接受率 .72→.94、独立正确率仅 .20，三家族一致仍接受约 55% 错误答案；judge-first 独立预判把假阳性 .719→.012。小说无客观解，不能照搬数字，但原则成立：**裁判必须在候选出现前预提交评价基准与因果预期**。
3. **分布外可靠性不足**：EvolvR（2025）StoryER Pearson .677 / HANNA .616，零样本 OpenMEVA 仅 .209；其生成故事人评胜基础模型 64.36%、胜人类故事仅 31.62%。要突破的是时间/作者/流派/文化切分下的外推，不是同分布提几个百分点。

## 三项能力判断

| 能力 | 结论 | 当前真正缺口 |
|---|---|---|
| 长程因果架构 | 高度可自动化 | 现有检查保证「不矛盾」，还需分支搜索、承诺价值与远期回报优化 |
| 原创世界观 | 生成和选择均有自动化路径，无已证明的原理禁区 | 世界规则的推导边 +「生产性原创」选择模型 |
| 终裁品味 | 可学习元品味并部分外推；无 78% 硬上限 | 目标不可识别、跨域泛化不足、闭环 reward-hacking、缺少长期结果监督 |
| 全自动大神级 | 合理研究目标，当前未被实证完成 | 生成器、因果系统、动态品味模型耦合演化 + 独立外部验证 |

关键变化：三项不是「前两项生成、第三项最后打分」的流水线，而是耦合搜索系统。品味从一开始指导世界规则与剧情分支探索；因果系统为裁判提供可验证客观约束；生成器的新候选反向暴露裁判盲区。

## 技术路线要点

1. **AuthorModule 保留为创作策略先验**，不承担全部终裁；另设审美组合：作者选择模型、多读者群预测、专家长期价值、新颖性×适切性、不确定性与分歧模型。不能简单多数投票（模型间可能共享同一种偏差）。
2. **世界观改「可推导世界」**：核心悖论/母题 → 本体规则 → 能力与资源法则 → 必须付出的代价 → 制度与权力结构 → 群体利益 → 人物策略 → 冲突与剧情压力。自动选择先比可验证属性：根规则推导出非平凡后果的压缩率、每个设定是否改变最优策略、删规则后剧情是否仍成立、冲突是否来自制度而非临时安排、新奇设定能否持续制造不同尺度剧情。
3. **候选群搜索替代一次生成一次裁判**：生成结构异质候选 → 确定性合法性检查 → 裁判看候选前预提交判断框架 → 分维评价 → 攻击代理专找「怪而无用」「熟而有效」「解释漂亮但正文没实现」→ 保留 Pareto 前沿 → 高分歧候选继续变体探索 → 跨章节观察兑现效果后更新选择模型。
4. **评价体系各司其职**：G7 只证某协议在冻结数据上的最低可靠性；blind_eval 证相对改善；pass_audit 证漏检；状态检查器证承诺兑现；元品味模型负责合法且有效候选间的探索排序；时间/作者/流派/文化外推测试证没记住已知审美。

## 最终裁决

- 保留：当前公开数据不代表大神专家品味；自动裁判易在专家尾部失效；闭环自我评价风险严重。
- 否定：78% 是硬上限；默会品味无法学习；模仿必然只奖励熟悉；原创天花板焊死在 base model；人类终裁原理上不可替代。
- 结论：未发现原理性不可行；已发现可检验的自动化路线。核心瓶颈从「品味不能模仿」改写为「如何学习动态、多群体、可外推的元品味，并在生成—裁判共谋下保持独立可靠」。
- 边界：允许利用既有人类作品、修订行为、专家选择与长期传播结果做离线学习；系统上线后自动生成、自动搜索、自动选择，无人工逐章介入；最终是否达大神级由独立、系统外证据验证，不由生成器自证。
