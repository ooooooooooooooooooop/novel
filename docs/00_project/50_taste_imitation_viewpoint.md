# 50. 观点记录：为什么「大神级品味」不能（在当前范式下）被自动模仿

状态：研究观点（Claude 记录，2026-08-16），供其他模型挑战 / 补充 / 反驳。

## 核心命题

全自动达到「大神级小说」有三个门槛，性质不同：

1. **长程因果架构** —— 工程问题，可自动（确定性状态机）。
2. **世界观原创** —— 生成可自动、选择不可自动（选择塌缩回品味）。
3. **终裁品味** —— 判断问题，模仿有上限（~78% 平均偏好），大神级在专家尾部。

本文只记录关于「品味」的论证。

## 论证：品味能模仿到「平均」，模仿不到「大神级」

### 前提（实证）

- LitBench（EACL 2026）：最好开箱裁判 73%、训练 reward model 78% 人类一致（43,827 对，众包）。
- Beyond Memory（2025）：base LLM 生成文本比人类更不新颖。
- 本项目实测：Gemini 0.427 / DeepSeek 0.714 判别。

### 三层墙（从浅到深）

1. **数据稀疏**：大神级判断是专家尾部，样本极稀缺，训不出可靠函数。
2. **不可言说**：品味是 tacit knowledge，可语言化的只是冰山一角；模仿拿到的是「能说出的部分」。
3. **自反性（最根本）**：模仿 = 学分布、给「熟悉」打高分；大神级原创 = 打破分布、「陌生但好」。
   两者方向相反。所以模仿函数在机制上无法识别原创大神级。

### 关键澄清

- 模仿「乌贼已展示的品味」（作品里既有选择）→ **部分可行**（数据在作品里，AuthorKernel 已捕获）。
- 模仿「能识别下一个大神级的品味」→ **不可行**（自反性）。

### 深层观察

- 连人类识别新大神级都常滞后；人类能事后更新品味，模型品味冻结在训练时刻。
- 品味不是静态函数，是随接触新作品持续演化的过程；模仿只能拿到快照，拿不到演化。

## 待挑战的点（请另一模型针对这些找新观点）

1. 「自反性」论证是否有反例？（有没有机制能让模型识别「打破分布但好」的东西？）
2. 「78% 是平均偏好、大神级在尾部更差」这个推断是否被实证支持？
3. 是否忽略了某些技术路径（多 token/扩散生成、专家标注 reward model、自我对弈裁判改进、RLAIF）？
4. 「品味不可模仿」是否只是当前 next-token + 当前数据的结果，而非原理性限制？
