# ADR-16：无人在环大神级创作管线（三信号联合奖励 + 冻结锚 + 认证分离）（proposed）

状态：proposed，待用户裁定；研究实施默认关闭，不构成生产授权或自动终审资格。

## 决定

本 ADR 记录一份外部交接单方案及其总控适配条件：探索一条无人在环的研究性创作选择管线，以局内后果、冻结读者能量模型、结构对位与独特性三类信号联合奖励，用冻结锚和独立认证防止奖励漂移。它只能作为 off-by-default 的实验设计；在 DirectAPI、tier 边界和外部验证条件满足前，不得解释为当前系统已具备无人值守生产能力。

### 硬约束

1. **吸取 G7 教训。** 不得让 LLM 以一个总分充当审美裁判；历史 `position consistency 0.5` 的实证失败不能被重新包装成资格证据。专门轴、确定性门禁、盲评、漏检审计和系统外人类盲评仍须分层，不能用一个综合分替代。
2. **诚实表述。** 最多声称产物在结构上接近某种杰作模式，不得声称产物“是杰作”。没有外部认证时，必须显式标为“未经验证”。
3. **零成本契约。** 任一信号或管线能力关闭时，相关 prompt 字节必须与关闭前基线逐字节不变；该契约必须由回归测试锁死，而不是靠口头约定。
4. **隐私纪律。** 具体书名、作者名、正文、工作区名和机器路径不得进入 ADR、日志、锚库或共享证据；只允许使用公开、隐私中性的聚合统计和必要的证据元数据。
5. **回归基线。** 不得回归当前本地声明的 `2961 passed + 1 skipped（2962 collected）` 基线；该数字是测试声明，不是生产质量或审美资格证明。

## 三信号联合奖励

| 信号 | 机制 | 负责回答的问题 | 明确不负责的事 |
|---|---|---|---|
| 1. 局内后果奖励 | 将可继续性与承诺会计合成单一动力学目标；对候选 rollout 的状态后果打分 | 这条选择是否让故事状态更可推进、承诺更接近可兑现 | 不判断句子顺不顺眼、文风是否漂亮或“像杰作” |
| 2. 冻结读者能量模型 | 公开阅读行为数据一次性校准句级注意力/情感增量预测器，验证后冻结 | 读者注意力与情感能量是否按可重复的外部信号变化 | 不在生产中在线学习，不把模型输出当终审裁决 |
| 3. 结构对位 × 独特性 | 对 held-out 黄金母版做结构锚定，同时测与母版分布的偏离及与自身已提交文本的一致性 | 是否保留高价值结构关系，又没有坍缩成母版或自我复读 | 不把相似度本身解释成文学价值或作者身份认证 |

### 信号 1：局内后果

对每个候选先做 rollout，再从状态后果计算联合动力学目标。制造死路、硬矛盾、承诺逾期或无法继续的状态为坏；产生有效状态变化、使承诺进入可兑现态、并保留后续选择空间为好。评分对象是故事状态的可持续演化，而不是表面流畅度或读者“顺眼”程度。

### 信号 2：冻结读者能量

设计一个句级注意力/情感增量预测器，由公开阅读行为数据一次性校准；启用前做一次性外部验证并冻结参数。若相关性低于预先声明的阈值，则不启用该信号，不能在管线内通过重新调参把验证失败改写成通过。该信号不接受在线漂移，也不承担审美总裁判职责。

### 信号 3：结构锚与独特性

准备一套公开、隐私中性的 held-out 黄金母版语料库，仅作为评估锚，不得作为训练材料。结构对位使用距离衰减，避免选择器反复贴近锚点而获得投机高分。独特性同时包括：相对于母版分布的有意义偏离，以及相对于自身已提交文本的自一致；前者防止模板复制，后者防止通过随机扰动冒充创新。两项都必须与故事后果和硬门禁分开报告。

## 认证分离

无人在环不等于无证据。唯二的人类接触点只用于审计或实验，不参与日常候选选择：

1. **能量模型验证：** 在启用信号 2 前，由外部实验一次性验证其相关性；失败则保持 design-only/关闭。
2. **大神级声称验证：** 若系统要声称“大神级”，做一次系统外盲评，复用现行五层评价中的第五层；否则永久保留“未经验证”标注。二者的选择必须显式写进系统配置和产物元数据。

认证不回写生产奖励，不由生成模型自证，也不把一次盲评变成永久生产资格。G7 的退役状态和五层评价的分工不得被本 ADR 逆向恢复成自动终裁。

## 生产分工（研究性全自动原型）

| 角色 | 工作 | 边界 |
|---|---|---|
| opus 类起草器 | 生成候选草案或候选结构 | 不自评总分、不授予资格 |
| flash 类筛检器 | 做快速筛检、结构反方和明显失败排除 | 不替代确定性会计、外部认证或最终审计 |
| 确定性层 | 承诺会计、状态一致性、硬门禁与隐私检查 | 不对文学审美做不可解释裁决 |
| rollout 搜索选择器 | 扩展候选状态并按三信号/Pareto 前沿选择 | 应升级现有 `simulate_state_driven_rollout`，不能绕过 Proposal/提交门禁 |

## 落地清单

1. **T1：黄金母版。** 定义锚库 schema、来源清单、held-out 规则、距离衰减和隐私检查；明确锚库只做评估、不进训练。
2. **T2：能量模型。** 设计一次性校准和外部验证实验，预先声明相关性阈值、失败处置和冻结格式；验证不足时保持 design-only。
3. **T3：选择器接入。** 将三信号接到 rollout/Pareto 选择器，提供默认关闭的独立开关；验证关闭时 prompt 字节不变，并补零成本回归。
4. **T4：认证闸。** 将外部验证和“大神级”系统外盲评接入现有门禁链；产物必须记录认证状态，未认证时只能使用“未经验证”标签。

## 预警指标

- **奖励分与锚距离长期背离：** 可能表示选择器在游戏化奖励，需暂停并检查信号权重、距离衰减和候选分布。
- **draft-vs-committed 漂移上升：** 可能表示审查或奖励正在制造 homogenization，需比较草稿与提交稿并停用相关奖励路径。
- **作者选择分布收窄：** 可能表示 self-imitation 或候选坍缩，需检查选择多样性、rollout 分支和自身文本一致性指标。

## 实施前置条件（总控适配的四点修正）

### 1. 信号 2 先降级为 design-only

公开的句级中文读者能量数据在当前证据中尚未证实可得；即使数据出现，冻结模型仍有 domain-shift 风险。因此第一阶段只能按信号 1 + 信号 3 两信号运行，且保持 off-by-default。只有在数据来源、一次性校准和外部验证均成立后，才能由用户或总控显式激活信号 2。

### 2. DirectAPI 是无人值守生产的独立硬依赖

交接单漏列了 DirectAPI。全自动分工需要管线内的模型调用，而仓库当前仍是 staged CLI/FileExchange 形态，DirectAPI provider calling 尚未实现。DirectAPI 的接口、权限、成本、失败安全和生产边界必须作为独立任务完成；在此之前，不能把“opus 起草 + flash 筛检”写成现有生产能力，也不能用人工物化 response 冒充无人值守。

### 3. tier 边界必须由用户另行裁定

现行边界是 `closed-loop automation remains disallowed`。因此 off-by-default 的研究实施与现行边界不冲突，但一旦要在生产中启用无人闭环，必须获得用户另行的 tier 决策；本 ADR 不自动升级 tier、不授予生产资格，也不改变 G7/G8 的退役结论。

### 4. T1 与本地 130+ 作者合集汇合

T1 应与正在入库的本地 130+ 作者合集汇合：黄金母版锚可以在本地计算统计指纹，但共享或提交的只应是中性聚合，不得携带书名、作者名、正文、原始路径或可逆识别信息。合集只是数据治理和统计锚的输入，不是作者模仿授权、生产资格或自动终审依据。

## 非目标、后果与裁定项

- 本 ADR 不实现 DirectAPI，不实现三信号，不新增训练语料，也不改变现有生产门禁。
- 本 ADR 不宣称质量已被证明；它只提出可证伪的研究设计和认证边界。
- 预期收益是把“故事能否继续”和“结构是否退化”从审美总分中拆出，并让外部认证与生产奖励分离。
- 主要代价是需要黄金母版治理、一次性验证实验、rollout 计算预算和新的失败监控；信号 2 还可能因数据不可得或 domain shift 永久不启用。
- 待用户裁定：是否允许进入 off-by-default 研究实施；是否接受信号 2 的 design-only 前置条件；是否在未来通过独立 tier 决策启用生产闭环；是否选择一次性系统外盲评，或永久保留“未经验证”标注。

## 证据与隐私铁律

本 ADR 只引用中性系统边界、测试基线和研究设计，不收录任何具体作品或作者信息。实现、测试、日志、报告和锚库必须遵守同一隐私纪律；无法确认数据用途、来源、脱敏状态或认证状态时，默认不处理、不启用、不声称。所有新增开关必须有关闭路径，关闭路径必须保持零成本契约和旧 prompt 字节回归。
